# Frontend smoke-test checklist

- [ ] Splash automatically opens Introduction, then Role Selection.
- [ ] Customer: role → login/register → service → regular/quick request → review → tracking.
- [ ] Customer: quotation review → payment/completion → review → bookings/profile/complaint.
- [ ] Provider: login/register → verification → jobs → availability → execution → quotation → payment/completion → earnings/profile/reviews.
- [ ] Admin: separate login → dashboard → users → services/rates → bookings → verification → complaints → settings.
- [ ] All forms show native required-field validation.
- [ ] All controls respond; demo changes persist in localStorage.
- [ ] Check widths at 1440px, 1024px, 768px, and 390px.

Note: This is a frontend demo. Authentication, payment, provider verification, notifications, and admin operations are simulated until backend integration.
